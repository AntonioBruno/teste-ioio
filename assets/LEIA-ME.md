# Bolos + Delícias da Ioiô — pacote individualizado para validação

## Conteúdo
Pastas: `assets/branding`, `assets/bolos`, `assets/docinhos`, `assets/salgados`, `assets/decoracoes`, `assets/icons`.
Arquivos PNG e JPG individualizados da prancha visual aprovada. Consulte `manifesto.json`.

## Limitações técnicas IMPORTANTES
- A prancha original possui apenas 1536 × 1024 pixels. Os arquivos foram recortados e ampliados por interpolação Lanczos, **não** recriados a partir de fontes originais de alta resolução. O número de pixels maior não significa detalhe fotográfico novo.
- O logotipo foi mantido como recorte da versão validada, mas não possui transparência verdadeira.
- As ilustrações decorativas e ícones podem manter fundo branco, xadrez, bordas ou restos do painel, pois a prancha não fornece camadas separadas. PNG não implica fundo transparente.
- Alguns recortes podem conter bordas ou detalhes de elementos vizinhos.
- Este pacote serve para validação e prototipação, **não é um conjunto final de assets pronto para publicação**. Para produção, é necessário obter as artes originais por camada (ou regenerar cada item) e fotos independentes de alta resolução.
- Não contém depoimentos fictícios ou dados bancários. Confirmar telefone e outros contatos com a cliente.
- Não contém HTML, CSS ou JavaScript, conforme solicitado.
